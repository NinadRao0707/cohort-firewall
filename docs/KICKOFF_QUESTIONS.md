# Questions to ask at the Nov 11 virtual kickoff

Rules and format
- Is code written before the build days allowed, or must the repo start on Nov 12?
- What are the judging criteria and their weights?
- What is the submission format (repo link, video, live demo)? How long is the demo slot?
- Do teams present on Nov 14 to all judges or in track rooms?

Data
- Will organizers provide reference datasets or "proposed AI questions" for the Cohort Firewall track?
- Which datasets count as event-approved? Is Synthea output acceptable?
- Is there an expected input format (CSV, FHIR, OMOP)?

Definitions
- Do the organizers have their own definitions for Ready / Conditional / Blocked / Insufficient Evidence?
- Is the tool expected to handle one dataset at a time, or compare several?

Stack
- Is any platform or model required or preferred (Red Hat OpenShift AI, a specific LLM)?
- Will API credits or compute be provided? Is internet available at the Cabral Center for the demo?

Logistics
- Team size confirmation and whether teammates can be added after kickoff.
